# Stephanie Romacho — Portafolio

Portafolio de **Stephanie Romacho**: estrategia, marketing, branding, diseño gráfico y comunicación visual.

Stack: React + TypeScript + Vite + Framer Motion + Lenis + CSS. Incluye la página de CV en `/resume` (con botón para imprimir o guardar como PDF).

```bash
npm install
npm run dev
npm run build
```
